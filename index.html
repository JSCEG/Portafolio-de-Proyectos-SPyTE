Geovisualizador de Áreas de Interés

Suite de cuatro versiones (V0–V3) que automatiza el análisis de KML con hasta 14 capas temáticas, buffers configurables y reportes Excel.

  • Versiones dedicadas para cargas rápidas, enfoque en localidades, multicapa y multi-área.

  • Reportes automáticos en Excel/PDF con métricas comparativas por área.

Tecnologías detrás

Arquitectura híbrida preparada para escalar.

Combinamos infraestructura Azure, capas de datos geoespaciales y componentes front-end modernos para mantener la continuidad operativa del ecosistema SENER/SNIEn.

Azure App Service Azure SQL Database .NET MVC / C# JavaScript / TypeScript Python Turf.js D3.js Highcharts jQuery DataTables Cloudflare CDN Múltiples capas geoespaciales Rasters de viento y potencia FV Capas de infraestructura energética

Infraestructura y datos

Despliegues sobre Azure App Service con pipelines CI/CD y bases Azure SQL segmentadas por módulo.

  • Conectores seguros a BD institucionales y autenticación federada.
  • Cloudflare y CDNs para resiliencia y tiempos de carga bajos.

Capa de aplicación

Servicios .NET MVC en C#, APIs Node/Express y automatizaciones Python para ETL y reportes.

  • Jobs Python para consolidar series históricas y métricas.
  • Workers .NET que entregan datos normalizados a los tableros.

Visualización y analítica

Front-ends modulables con JavaScript, TypeScript, Turf.js, D3.js y Highcharts.

  • Tablas avanzadas con jQuery DataTables y exportaciones CSV/PNG/SVG.
  • Componentes reutilizables para storytelling y controles mobile-first.

Geoespacial

Mallas vectoriales y rásters energéticos (viento, potencial fotovoltaico, infraestructura).

  • Capas Leaflet/WebGL para ductos, subestaciones y proyectos estratégicos.
  • Buffers dinámicos y filtros temáticos para análisis territorial.
